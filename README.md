TaskPilot is a clean, modern, and fully responsive To-Do application designed to help users stay organized and productive.  
It includes features like task search, priority levels, categories, dark mode, and local storage persistence — making it simple yet powerful.

🌟 Features
✅ Add, Edit, and Delete Tasks
Easily manage your daily tasks with a simple and intuitive UI.

🎯Priority Levels
Choose between:
- Low
- Medium
- High

  Tasks are highlighted visually for better clarity.

 📂Task Categories
Organize tasks into:
- Work  
- Personal  
- Study  
- Health  

🌙Dark Mode Toggle
Switch between Light and Dark mode with a smooth UI transition.

📊Task Stats
Real-time counters:
- Total tasks  
- Completed  
- Pending
  
📱Responsive Design
Looks great on:
- Desktop  
- Tablets  
- Mobile phones

🛠️Tech Stack Used

- HTML5 – Page structure  
- CSS3– UI design, animations, dark mode  
- JavaScript (ES6) – App logic, CRUD, LocalStorage  
- Git & GitHub – Version control & hosting  
- GitHub Pages– Live deployment
